## 지속 송수신

| 실행 | 조건 | 송신 / 수신 / DB | 판정 |
|---|---|---|---|
| `ps1025b1` | 구독 대기 500ms | 56 / 111 / 56 | 상대 서버 사용자에게 첫 메시지 1개 누락 |
| `ps1025c1` | 구독 대기 3초, 교대 송신 간격 5초 | 22 / 44 / 22 | 대조 오류 0 |
| `ps1025d1` | 같은 대기 조건, 15분 | 358 / 716 / 358 | 대조 오류 0 |

- 연결: v1/v2 직접 연결 한 쌍과 서비스 주소 연결 한 쌍
- 초기 누락 원인 미확정. 3초 대기 통과는 초기 구독 직후 무손실을 입증하지 않음
- `/ws` 원본 전환 후 원복은 부하 종료 뒤 수행. 부하 중 롤백 미검증
